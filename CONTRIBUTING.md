# المساهمة | Contributing

[العربية](#العربية) · [English](#english)

## العربية

مرحباً! نقدر نضيف أي أداة ذكاء اصطناعي مفيدة لأهل الكويت والوطن العربي 🇰🇼

### أسهل طريقة
افتح [Issue جديد](https://github.com/29kuwait/kuwait-ai-directory/issues/new/choose) واختر "اقتراح أداة"، وعبّي النموذج. ونضيفها نحن.

### إذا تبي تضيفها بنفسك
1. اضغط **Fork** للمشروع.
2. في ملف `index.html` أضف سطراً جديداً داخل المصفوفة `T` بنفس شكل الأسطر الموجودة: الاسم، الوصف بالعربي، الوصف بالإنجليزي، الرابط، الفئة، السعر، "كيف تبدأ" بالعربي والإنجليزي.
3. أضف الأداة في جداول `README.md` بلغتين.
4. افتح **Pull Request**.

### شروط الأداة
- رابط رسمي يشتغل.
- السعر صحيح: `free` مجاني، `part` مجاني جزئياً، `paid` مدفوع.
- بدون إعلانات أو روابط تسويقية أو أدوات مشبوهة.

شكراً لمساهمتك!

## English

Welcome! We are happy to add any useful AI tool for people in Kuwait and the Arab world 🇰🇼

### The easiest way
Open a [new issue](https://github.com/29kuwait/kuwait-ai-directory/issues/new/choose), choose "Suggest a tool", and fill in the form. We will add it.

### Adding it yourself
1. **Fork** the project.
2. In `index.html`, add a new row to the `T` array, matching the existing rows: name, Arabic description, English description, URL, category, price, and the "how to start" tip in Arabic and English.
3. Add the tool to the tables in `README.md` in both languages.
4. Open a **Pull Request**.

### Requirements
- A working official link.
- Correct price: `free`, `part` (freemium) or `paid`.
- No ads, affiliate links or suspicious tools.

Thank you for contributing!
